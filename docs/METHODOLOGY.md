# Methodology

The wording served in the product is `GET /api/v1/methodology`, generated by `methodologyDocument()` in `packages/analytics`. This note is the same model, shortened.

## Labels

- `PROTOCOL-EXACT` — EIP-1559 integer update, or gas used compared with `gasLimit / 2`.
- `OBSERVED ON-CHAIN` — header, transaction, or receipt fields.
- `INFERRED` — curated address book or a known 4-byte selector. A selector collision is not treated as an application identity.
- `UNVERIFIED` — no match, missing receipts, or a base-fee step that does not equal the child header.
- `MODELLED` — gas removed on paper and the base fee replayed. Builders could have included different transactions.

## Execution base fee

Target = `gasLimit / 2` (integer). Parent gas sets the next block’s fee.

- Equal to target: next base fee unchanged.
- Above target: `delta = max(1, parentBaseFee * excess / target / 8)`.
- Below target: `delta = parentBaseFee * deficit / target / 8`, with no 1-wei floor.

The change from the first block’s base fee to the last block’s base fee is produced by the parents inside the window (every block except the last). The last block is what moves the following fee. Gaps set the match to unknown instead of calling the formula wrong.

Gas used is the receipt value. Gas limit and `maxFeePerGas` are caps. A reverted transaction still uses gas.

Execution fee = `gasUsed * effectiveGasPrice`. Burn = `gasUsed * baseFeePerGas`. Tip = execution fee minus burn, floored at zero. Blob fee = `blobGasUsed * blobGasPrice` and is not execution gas.

Standard / Fast / High = latest base fee plus nearest-rank priority p50 / p75 / p90. They are estimates. There is no ETH/USD feed, so the UI does not show dollars.

## Blob schedule

Compiled 2026-11-02. Override with `BLOB_SCHEDULE_JSON` if a newer blob-parameter fork is active. Cancun, Prague, Osaka, BPO1, and BPO2 are in the code. BPO3 was not a scheduled mainnet fork in the execution specs used for this build. Osaka and later apply the EIP-7918 reserve price. `GAS_PER_BLOB` is 131072. Excess blob gas of zero prices the blob base fee at 1 wei.

## What this does not claim

A large sender can be most of the gas in above-target blocks and still not be “the cause” of the network. Internal calls are invisible without traces, and traces run only when `TRACE_ENABLED=true` and the provider supports them. Explorer gas charts are not an input.
